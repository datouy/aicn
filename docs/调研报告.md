# GitHub 调研报告：国内 AI / Web 开发辅助工具生态（2026-10）

> 调研时间：2026-10-26　方法：GitHub Search API + 网页数据核对（stars 均为实时抓取）

## 一、调研结论速览

- **中转/网关类**（one-api / new-api / LiteLLM / claude-code-router…）是红海，头部项目 3–6 万 stars，新进入者很难有优势；
- **客户端 / RAG / 机器人** 同样拥挤（chatbox 42k、cherry-studio 53k、lobe-chat 83k、dify 159k）；
- **真正的空白在「配置与诊断层」**：把国产大模型接入 Codex / Claude Code / Cursor / Cline 时，几乎没有人做"零依赖、一条命令完成查价→测协议→写配置"的工具（最接近的 relay-switch 仅 32 stars，且只覆盖中转站切换）；
- 2026 年新趋势集中在 **token 成本压缩（rtk 84.5k）、本地代码图谱（code-review-graph 32.4k）、Agent 控制面（claude-code-router 37.8k）**。

基于以上判断，本目录立项并完成了 **`aicn`**：一个零依赖的配置+诊断 CLI（详见 `../README.md`）。

## 五、为什么先做 aicn

1. **痛点高频**：每个国内 AI 开发者接入 Codex/Claude Code/Cursor 时都会踩一遍协议与配置的坑；
2. **生态空白**：网关类 3–6 万 stars 的项目一堆，配置诊断层最接近的只有 32 stars；
3. **零依赖易维护**：单文件 Python + 纯 JSON 数据，社区 PR 更新价格/模型名即可持续；
4. **符合开源起步定位**：代码量适中、文档完整、测试齐全，适合作为个人 GitHub 的第一个正式项目。

## 六、aicn 已完成 vs 路线图

**已完成（v0.2.0）**：`list`（价格/协议查询）、`test`（chat/responses/anthropic 三协议实测，失败返回非零退出码）、`gen`（Codex/Claude Code 一键写入 + 自动备份，Cursor/Cline 界面指引）、`env`（密钥环境变量命令）、`doctor`（网络/配置/密钥体检，按状态码分级）、`sync`（从 `/models` 同步模型到用户级数据文件）；零依赖 Web 面板 `web`；98 个单元测试 + ruff 静态检查 + 三平台 CI 矩阵（含 Python 3.14）。

**v0.2.0 修复要点**：Web 面板并发输出隔离（命令函数以返回值传文本，不再劫持进程级 `sys.stdout`，避免 A 请求的输出与密钥串进 B 响应）、模型 id 的 HTML 转义（`esc()` 覆盖 `& < > " '`）、`env` 位置参数与 `--provider` 等价（README 里的 `aicn env qwen` 可直接跑）、`test` 失败返回非零退出码（401 / 连接不通 / 200 带 error 体 / 200 非 JSON 均判失败）、`main()` 契约统一为「永远返回 int」（argparse 报错也转成退出码）、`sync` 只写用户级 `~/.aicn/providers.json`（不再写包内或仓库里的 `providers.json`）、写入失败（无权限）干净报错而非抛 traceback、面板「✏️ 自定义…」模型输入框恢复可用、协议标注显式化（Anthropic 官方不再被误标为 chat）、Claude Code dry-run 预览与实际写入一致、表格列对齐、密钥可从 stdin 读取。

**协议数据校正（依据官方文档与端点实测）**：DeepSeek 官方同时提供 chat / Responses / Anthropic 三种协议（`https://api.deepseek.com/anthropic`），此前被误标为「只有 chat」；Moonshot 官方有 `/v1/responses` 与 `/anthropic/v1/messages`；豆包官方有 `POST /api/v3/responses`；百炼的 Anthropic 端点是 `/apps/anthropic`；SiliconFlow 的 Anthropic 端点是 `/v1/messages`（**不是** `/anthropic/v1/messages`，后者为 404）；智谱的 Responses 基址是 `/api/v1`，与其对话补全的 `/api/paas/v4` 不同 —— `aicn` 现按协议自动取对应基址。价格数据同步更新：DeepSeek 改为美元计费，模型名更新为 `deepseek-flash` / `deepseek-v4-pro`、Kimi K3.1 Pro、Qwen3.7/3.8、Claude 5.5 系列等。

**路线图**：`gateway`（本地协议转换）、用量统计、价格自动更新、Windsurf/Trae/Kilo Code 支持、TUI。
